# Cálculo y Diseño de Estructuras · App de estudio

Aplicación web de estudio para la asignatura *Cálculo y Diseño de Estructuras* (Máster en Ingeniería Industrial, ETSII-UPM).

- **Modo aprendizaje**: 41 esquemas, 29 ejercicios para clasificar y relacionar, trucos de memoria, 19 lecciones guiadas con diagramas y comprobación final, 96 tarjetas con repetición espaciada, temario completo, resúmenes, confusiones frecuentes y 257 preguntas nuevas con explicación.
- **Modo exámenes**: PA1 de 11/11/2025 (versiones T1–T4), transcrita literalmente y corregida con la hoja oficial de soluciones; simulacro de 40 min, revisión e historial.

Es una web estática (HTML/CSS/JS) sin instalación. El progreso se guarda en el navegador (localStorage).
